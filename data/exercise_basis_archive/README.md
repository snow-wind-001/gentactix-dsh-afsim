# Frozen exercise references

These public reference snapshots preserve the exact inputs used by older synthetic exercises when a historical card changes. Filenames are the complete `basis_hash`; loading verifies that hash, the battle, and the reference format. Unknown or modified references remain rejected. New exercises continue to use the current card.

`b35ae4dd…23300.json` is the Wuhan reference recovered from the saved public `get_scenario_basis` result of an existing exercise. Its complete digest and the reconstructed exercise definition were checked against that checkpoint. It contains historical reference text and citations, with unknown personnel, equipment, and tactical positions preserved as `null`; it contains no credentials, private SDK journal, combat results, or saved game state.
