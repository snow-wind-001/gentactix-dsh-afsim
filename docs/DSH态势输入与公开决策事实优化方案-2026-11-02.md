# DSH态势输入与公开决策事实优化方案

本方案来自22单位真实连续推演。可逆来源编码已完成离线实现及回归，并在原22单位第6轮实际主提示中使用、提交和精确回验；独立引用理解及性能对照尚未完成。公开决策事实展示仍待实现，不替代当前主线及完整历史验收。

## 当前实施证据

`gentactix/observation_codec.py`仅对来源上下文的重复长字符串建立随观察携带的正文表，原始引用形状文本有转义；解码核对来源及完整观察，无收益时保留旧格式。`dsh_simulation.observation_view`保持原投影，编码发生在其后，候选提交及来源守卫不变。DSH继续管理会话压缩。

同一22单位轮初观察生成的基础提示从194694字符／374610个UTF-8字节降为107184字符／153792字节，全部单位、数值及来源正文精确还原；不能据此宣称同比提速。9项新回归、45场57份冻结资料往返检查及最终96项相关回归通过，原增量完整离线151组／1748项、0失败／0跳过。原连续验证进程保持优化前源码，最终因Native单位JSON连续两次不合法而在第6轮未提交。后续[结构化单位候选修复](Native单位结构化候选与运动反馈核查-2026-11-02.md)从原第5轮重试成功；实际主提示编码存在、全部22身份及205项来源字段保留，精确观察回验与冷恢复通过，当前完整门禁152组／1763项通过。本轮耗时约29分钟且有工具纠错与4次原生压缩，不能将此称为独立性能对照；运动反馈仍未通过。证据`.cache/qa/observation-encoding-2026-11-02/`及后续报告目录。

## 已确认的问题

- 取DSH第三轮轮初权威世界，通过现有`dsh_simulation.prompt`只读生成输入，已有194694字符／374610个UTF-8字节，尚未计额外全局指令和史料补充。
- 22单位的`source`、`assumption`及`parameter_sources`中，396次字符串出现只有22种不同内容，重复部分达96766字符。重复的来源说明约占该输入字符的一半；这不是可直接宣称的token或时延降幅。
- 第三轮经历DSH原生上下文压缩后实际提交，前端请求耗时925.705秒，22单位、阶段、人员装备账和原单位会话连续。预算为64K输出／256K上下文／1800秒单请求、32步及128次工具，未降低思考强度。不能只用增大窗口解决重复输入。
- 第90师公开说明把同一敌距先写约5.4公里又写约1.9公里；轮初坐标计算为5.371公里。动作合法性校验通过不等于说明文字准确。

证据：`.cache/qa/wjl22-continuous-2026-11-02/prompt-provenance-size-review.json`、`native-explanation-issue.json`及`native-compaction-postcommit.json`。没有读取原始DSH日志或内部推理。

## 实施顺序

1. 先继续现有主线并保留全部原输入／结果，取得合法目标结算或明确的未通过原因，不重置初态、不缩短目标距离。
2. 在宿主观察格式中对**完全相同的来源说明**建立可逆引用表；保留所有单位、身份、数值、坐标、库存、关系和不确定性。来源正文保留在同一观察表或现有检索入口，不能把去重改成删除限制说明。它是请求编码优化，DSH仍负责自己会话的上下文压缩。
3. 单位公开决策旁提供宿主计算的轮初事实：观察版本、坐标、目标距离、行动预算、射程与资源。复用已有观察／命令校验，不另造态势存储或战果计算器。自由说明继续标作模型说明，保留原文，不自动包装成已核事实。
4. 使用原生工具与同一会话复核结构化事实；只对可判定字段作硬校验，文字歧义单列审计。不能声称几个距离正则即可核验全部军事解释。

## TDD与验收要求

- 先对真实22单位轮初状态及多版本存档建立失败测试。编码后解码须精确恢复原观察；宿主世界、定义、身份、人员装备和库存摘要不变。不同来源／估计不能被错误合并。
- 证明输入中仍含全部22单位及完整规则数值；非法引用、缺失来源、把只读引用写成状态更新均拒收或给明确反馈。沿用原候选提交与原子守卫，不修补模型战果。
- 对5.4／1.9公里原错误样本，宿主事实列表必须显示5.371公里及对应版本；模型文字仍有错误时保留未通过标记，不能靠改写原记录得到通过。
- 跑相关配置、状态、报告、资源与上下文回归，再跑仓库既有全量检查。实际DSH／AFSIM及前端复测均保留全部单位、相同思考强度和输出预算，核对原会话／任务连续性。
- 时延至少记录多轮请求字符、实际SDK用量、压缩事件、耗时与失败；区分冷启动、缓存和服务负载，不承诺字符减少等于同比提速。原22单位基线和失败证据必须保留。

历史资源标定、道路／地形、航空、其他44场资料与270完整历史窗口仍按原规划推进；本方案不关闭这些缺口。
