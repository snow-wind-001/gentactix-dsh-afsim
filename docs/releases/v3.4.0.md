# 3.4.0 本地安装验收

本版将地图工作台、统一团级AFSIM教学模型和严格史料事件回放纳入完整Linux安装包。已替换本机用户级AppImage及菜单、桌面快捷方式，未上传GitHub。

## 界面与操作

地图成为工作台主体。顶部“推演操作／目标与运行／地图图层”可向上收起；左侧标签展开想定设置；原底部信息迁入右侧战报、损耗、航空、保障、裁决、因果、复盘、问答和摘要标签。三个面板默认收起，打开时覆盖地图，不压缩或重建Leaflet容器。

折叠保留意图草稿、图层选择和组件状态。窄屏面板互斥，侧栏不遮挡顶部入口；各面板独立滚动。Escape收起并恢复焦点，右侧标签支持方向键、Home、End。单位指挥和地图选点自动收起遮挡面板，时间、模式、结算状态、推进及在途取消保持可达。

界面沿用海军蓝工作台配色，统一标签、边框、间距、数据数字和焦点状态；采用紧凑常驻状态栏及清晰的面板层级。地图保留底图署名，未载数据和教学参数的来源说明仍可查看。1440×1000时地图为1352×952；本机1530×948窗口中为1442×900。

## 完整包内容

- 前端、Electron、Python冻结后端、战役资料及DSH/AFSIM适配器均已重新编译。
- 45项统一团级教学模型、20份旧版教学变体；严格史料模式仅执行有来源的事件帧。
- 新增原始JSON文本导出/导入，避免浏览器把`1.0`重写成`1`而破坏定义摘要。没有放宽规则、篡改或重复ID校验。
- 窗口和“关于”显示版本3.4.0，方便区分源码页、旧包与实际安装版。

AFSIM本体、Wine及用户密钥不包含在公开安装包中；本机安装通过原项目目录使用已有运行组件和加密配置。模型仍是教学抽象，未完成历史武器效能、DEM遮挡或逐发弹道标定；事件回放不等于完整历史单位轨迹复原。
