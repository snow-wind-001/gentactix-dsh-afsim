# 3.4.1 等待反馈与地图交互

本版已重新编译前端、Electron和冻结后端，替换本机AppImage、应用菜单和桌面入口。未上传GitHub；原模型配置、密钥及两份已有对局文件校验未变。

## 等待状态

地图最上沿增加3像素彩色细线，常驻状态栏显示当前阶段和本次操作已用时间。等待或DSH决策为青蓝色，AFSIM执行为琥珀色，接收校验为浅蓝色；成功提交后显示绿色，失败显示红色，取消完成显示灰色。成功与取消反馈停留4秒，错误保留至后续操作。

细线采用不定进度动画，不显示无法计算的完成百分比或剩余时间。状态连接短暂失败时继续显示等待；取消请求发出后，必须等实际操作结束才显示已取消。计时表示界面等待时间，不代表模拟世界推进时间。支持减少动态效果的系统设置。

## 操作与标签

- 左右标签采用浏览器页签式轮廓，选中标签与对应面板衔接，保留折叠、键盘切换及Escape操作。
- 等待期间“推进一轮”原位禁用，取消为独立按钮，避免连续点击导致重复推进或误取消。
- 运行状态串行轮询，设置超时并丢弃过期响应；完成后停止轮询。
- 等待计时独立更新；单位选择只更新选中样式。状态轮询、问答内容及选中变化不会重建地图单位。
- 地图渲染合并到动画帧，修复火力射程开关未隐藏团级射程圈，以及单个单位点击后出现重复弹窗的问题。

这些改动减少前端重复渲染，不改变模型推理强度、输出预算或后端计算算法，也不承诺缩短模型生成时间。
