# 万家岭阶段数值口径与全目录资料复核

本轮回到45场会战的可计算资料改造，补充阶段数值合同、万家岭增量档案与原始资料定位。**不代表完整会战或历史效能已验收。** 证据目录：`.cache/qa/campaign-materials-2026-11-02/`。默认版本、旧初态和用户配置／对局不迁移。

## 本次解决的问题

单位事实原有单一人数、装备值，不能直接表达不同日期、对象和口径的数字。研究材料中的“补充2700人”“每师选200—500人”“北退千余人”若直接填入同一兵力字段，就会造成重复补员、错误满编或把接敌群体当战损。

阶段现可登记`measurements`，保存单位关联、日期精度、指标与计量单位、数量关系、统计类别、对象范围、来源和限制。`eq`仅表示来源明确报数，`approx`仍为约数，`gt`仅为超过所记数，`range`保存原区间；不伪造误差或取中值。`unit_ids`是涉事关联，统计对象须连同`population`解读，不能给每个关联单位各分一份数字。

复用DSH已有`retrieve_history(kind=measurements)`，继承冻结阶段／定义摘要、单位筛选、分页及空筛选恢复。原生插件声明、历史编制skill和兼容工具说明同步更新，没有增加另一套传输或仿真器。数值资料不自动写当前人员、装备、库存、伤亡或胜负；未载不是零。
