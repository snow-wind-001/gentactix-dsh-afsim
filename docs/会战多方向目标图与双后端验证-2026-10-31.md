# 会战多方向目标图与双后端验证

> 2026-10-31，E03-B1分项实现记录。承接[总体规划](会战级多层编制与分合兵改造规划-2026-10-31.md)与[持续会战细则](持续会战任务图执行细则-2026-10-31.md)。这是目标评分组件的验收，不是完整持续任务、完整万家岭或45场历史会战的通过证明。未上传、未打包替换安装版；用户模型配置与既有对局未修改。

## 1. 本轮解决的问题

旧局部据点/阻援联合条件不足以表达多个方向分别完成、依赖与双方不同目标；提示词中又有无条件“截止回合结算”，与目标制冲突。本轮新增可选的`campaign-objectives-1`，在校验后的物理状态上由宿主评分，保留无此字段旧局的规则。

实现接点：`gentactix/campaign_plan.py`保存配置、图校验、进度与只读观察；`historical_operations`冻结参数；`missions`统一评分；`dsh_simulation`与`afsim_turns/afsim_comparison`分别产生物理结果后接入。DSH不能提交目标完成或直接改写目标图，AFSIM新图场景不再由旧单点终止表达式提前结束。地图与目标面板读取同一评分状态。

**目标依赖不等于命令调度。** 图不会自动向部队下令、释放预备队、取消任务或限制某条人工命令。发出—收到—准备—执行—完成的长期任务状态机仍待实现。

## 2. 当前契约与适用边界

显式参数`campaign_plan`包含版本、1—64个节点、双方`outcomes`、全军失能终止策略和估计说明。节点引用真实执行叶子ID，声明阵营、地域/资源等谓词、`all/any`前置、最早激活时点、保持时长、是否锁存，以及冻结史料中的事件ID。不能引用敌方为己方承担者、形成环或超出计算战区；事件关联不是强制历史结果。

| 项目 | 已实现语义 | 限制 |
|---|---|---|
| 条件 | 控制地域、到达、兵力保存、粮弹阈值、既有交通/组织/接收指标 | 不等于完整道路、运输或敌后算法 |
| 依赖 | 同方节点AND/OR；方向可并行，局部完成后全局继续 | 当前无跨方触发与支援能力分配 |
| 持续 | 连续满足的回合数；保持时长；里程碑锁存或持续条件 | 保持从首次满足的回合端点起算，不证明未采样轮内始终控制 |
| 结算 | 红、蓝各自条件；双方同时达成可平局；显式失能策略 | V1要求双方都有目标，不适合直接套用单方会师/转移 |
| 时间 | 目标制超出参考`deadline_turn`仍可继续 | 不代表完整阶段生命周期或无限稳定性已验收 |
| 编辑 | 明确传入的参数经API校验；合成增删/更名重绑成员 | 启动向导与DSH配置生成尚未自动提供目标图编辑，45场默认模板未迁移 |
| 恢复 | 配置与物理输入摘要、幂等评分、检查点恢复 | 旧相邻阶段入口明确拒绝迁移新图，避免静默清空进度 |

节点观察使用既有Native插件工具`get_campaign_objectives`，节点/成员每页最多16条。`plan_hash`标识静态配置，`view_version`标识本次状态；后续页必须携带视图版本，缺少或过期拒绝。节点只给成员样本和分页入口，不反复拼整场状态。新增工具沿现有角色权限、桥接与轨迹运行，未另造DSH协议，也未切换PTC。

## 4. 失败证据与未通过项

实际API曾返回502：最初目标输入摘要包含人员/编制的来源和执行回执元数据，物理值未变却被误判同轮改写。修复为只取谓词真正读取的身份、时钟、位置、人数、压制、粮弹及到场时点，浮点规范化；来源变化不误报、真正物理变化仍拒绝的回归通过。原失败日志保留。

最初前端选择器误用标签，改用实际控件角色后完整流程通过；未把首个失败删除。额外复查发现旧面板把目标评分一并归给AFSIM，现明确“AFSIM运动/领域规则，宿主目标评分”，蓝方结算也不再显示旧固定红方进度。

**仍未通过：**

1. DSH第3轮讲解称“五个步兵师”，没有保留161师“投入部”限定；并泄露`north/south/blue_exit`、`waiting_dependency`内部标识。身份与物理账正确，面向教学的自由讲解不能因此算全面准确。
2. DSH三轮粮量为78、76、74，弹药80，但旧`supply`仍80；地图弹窗直接读该字段。已证实展示数据源不一致，尚未修复。应先定义唯一派生口径，再对待命/移动/战斗/补给和两后端加TDD；不能把旧百分比当实际粮弹充足。证据`manual-quality-findings.json`。
3. 本轮是运动与目标评分QA，未安排交火；零战损不构成历史杀伤有效性证据。完整围攻、阻援、接替、地形过程和同范围历史损失未验收。
4. 10阶段、时间空档、撤出重入、在途运输、重编与非递归历史仍未实现；双仓运输、完整C2、展开/道路/视线以及粒度历史标定仍待建设。
5. 45场默认模板、三用途全组合、完整自由问法、长期无中断稳定性和安装版未验收。不能将本轮局部通过计为这些项目通过。

## 5. 后续执行顺序

先处理F06的已见补给展示不一致及F09讲解限定；随后E03-B2建立可取消、可恢复、保留人工优先的任务执行状态机，配合既有组织/命令，不复制新系统。再做E03-C/E04单世界生命周期，完成至少10阶段含空档/增援/退出重入/故障冷恢复。之后E05多仓运输、通信与接触，E06粒度/步长和同范围历史标定，最后按45场清单分批准入。
