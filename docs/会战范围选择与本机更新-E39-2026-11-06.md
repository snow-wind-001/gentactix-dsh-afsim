# 会战范围选择与本机更新（E39）

## 修复的问题

正常新建历史战局曾默认选择旧版局部阶段。万家岭因此只准备4个计算身份，即使资料库已有22单位会战窗口。新前端要求先明确选择局部阶段、限定会战窗口或累计编制，显示身份数、来源版本和估计性质。累计编制不是同日到场证明，不能据此宣称完整历史会战通过。

窗口默认只列各ID的最新版本；勾选后可使用旧版本。隐藏旧版本不会迁移已选窗口。读取失败、未选窗口或资料不足时阻止生成；异步旧响应不能覆盖新选择。旧存档保持原版本与计算范围。
