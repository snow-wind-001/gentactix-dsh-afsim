# 会战阶段数值资料接入方案

本轮承接45场会战资料改造，先在万家岭验证可推广的统计口径合同。不能把研究论文中的补充基数、选拔命令、接敌群体或撤退残部当作全师实有数；也不能由已知番号倒填未知兵额。现有单值`facts.personnel`不足以表示这些差异。

## 实现范围

复用冻结历史初态的阶段、单位和来源注册表，在阶段增加可选`measurements`数值资料。每条保留ID、涉及单位、日期精度、指标、单位、数量关系、统计类别、对象范围、来源及限制。数量区分明确数、约数、超过某数与区间；约数不伪造误差区间。所有记录均为资料参照，不自动写入单位人数、装备、库存、伤亡或胜负。

复用DSH已有`retrieve_history`插件工具，增加`kind=measurements`分页；沿用阶段／定义摘要固定、单位筛选、文字检索和空筛选恢复。原生工具声明与专用历史skill同步更新，不创建新传输或代理协议。旧快照没有该字段时保持原值及内容摘要。

## 资料与版本

视觉复核郭代习论文印刷119—120页后，新增万家岭1.4.0资料版本，登记补充基数、接敌群体、命令选拔和退却群体等不同口径。继续明确这是论文转述，未核馆藏原件；人数、装备初态缺载仍保持未知。已有版本和默认入口不改，新增版本可由既有目录发现；新的会战窗口必须重新绑定其定义摘要，不能冒用旧版本来源。

保留有据的部分编制覆盖及余部边界。网络档案目录可检索不等于扫描原件已读；无法读取的地图和详报不用于填精确阵位、逐团损失或实有装备。

## 检测出口

先写失败回归：不同统计对象不能混作当前状态，缺来源／非法单位／错误数量关系必须拒收；旧版摘要与默认版本不变；跨阶段分页不串页；新窗口与新来源绑定。再跑相关回归和完整根目录门禁。

使用真实DSH沿现有只读工具核对各类数字及其不可推出的结论，检查公开工具记录与答案，不读取模型私有思考。这项通过只证明数值资料读取与口径区分，不能代替完整历史推演、资源标定或270个历史窗口验收。随后继续逐场补阶段部署、后勤与兵种效能，优先万家岭和武汉。
