# 军事标图接入设计

## 数据与范围

原库含256个独立示例、234个组合区、23,544个自动笔画组及213页底稿。目录明确未逐项认证语义与年代，且未授予原书商业发行权限。工程保留本地参考访问，公开安装包采用35个项目矢量重绘图例与来源元数据，不打包原扫描库。

应用图例为24单位画布、统一线宽和显式定位点；指挥所按旗杆脚定位，其他按目录锚点。图形、颜色、阵营、来源和部队身份分开。未知兵种显示未知，不以形状推定国别或型号。现有兵种解析点继续使用`unit_types`。

## 界面与状态

`App → MapWorkbench → MilitaryPlottingPanel`负责目录、编辑及草稿；`MapView`只绘图和回传选点。点一次落位；线及地域连续选点后完成。标注列表支持编辑、删除、显隐；部队显示图例可以独立更改。键盘Escape退出选点，收起面板不丢草稿，窄屏沿用现有侧栏。跟随单位的标注用引线旁置，不覆盖作战军标点击区域。

`session.plotting_state`持有版本、独立修订、标注及单位图例覆盖，不写`war_state`。保存检验标图修订和战局摘要；世界变更时旧草稿拒收。绑定单位的点随当前观察位置显示；静态点保留地图坐标。保存、导出与恢复保留标图数据。图形不参与AFSIM战斗、道路、补给和目标判定。

## API与DSH

目录与原库参考为只读接口；会话标图GET/PUT使用相同会话存储和操作锁。`plotting/propose`经现有DSH会话与Cordis工具调用专用skill、检索图例、校验候选；只返回待确认草稿。位置限用户地图选点或当前已知位置，模型不能写SVG、文件、权威状态或猜测坐标。在途取消复用现有机制。

核心维护位置：`gentactix/military_symbols.json`、`military_symbol_reference.json`、`tools/build_military_symbols.py`及`plugins/dsh-military-plotting/skills/military-plotting/SKILL.md`。前后端共享同一词表，图库与规则均可版本化维护。

## 验证

先验证几何、定位点、过期草稿、未知图例、SVG参考白名单及状态隔离；再验证实际DSH三工具调用、手工/模型草稿确认、地图点线地域、导出恢复及现有回合不丢标注。检查大/小视口、单位点击命中与不可信文字转义。标图不作为历史真实性或AFSIM新能力的证明。
