# 单位参与状态、退出重返与原任务连续性验收

范围：会战规划K01及E04-B1的同世界后方待命／重新投入子项。使用六个具名历史身份及明确QA参数，另验两成员任务群；不是完整万家岭、45场历史准入、真实场外过程或历史效能标定。证据目录：`.cache/qa/unit-participation-2026-11-01/integration/`。

## 1. 已实现的行为

- 普通移动保持原语义。明确退出当前作战或重新投入时，公共命令附`participation=withdraw|reenter`，须为`move + until_arrived`；地图提供最终地域，宿主保留最终目的地并逐轮裁剪实际机动段。
- 队列、上级编组、持续任务、自然语言草稿、Native单位规划、保存校验复用同一`commands.DRAFT_FIELDS`。请求ID在持续机动中不变，不能由模型直接改参与登记。
- 宿主在物理执行和时钟结算后、目标评分前更新状态。状态包括待入场、在场、退出途中、后方待命、重新投入途中；到达回执成立才进入后方待命或重新投入完成。没有实际执行的请求不冒充到达。
- 后方仍在同一世界，有实际位置和同一人员／装备／库存账，可受远程打击；后方及返场途中不能直接进攻或承担作战目标。失能仍由实际人员判断，后方标签不生成兵力或隐身。
- 明确参与机动临时让原持续任务等待；返场后按原权限、前置和截止窗口恢复。暂停阶段下发明确待命，`activated=false`，不计原任务完成次数。普通人工接管仍保持原来的永久接管语义，不暗改旧命令政策。
- 两后端及现有只读对照均接入；DSH通过既有观察、分页工具、Native候选预览与公开轨迹读取状态，无新运行时或第二套聊天账本。地图保留军标，增加状态文字；单位和编组面板可选择参与方式、地图目标、预览及确认。

能力需同时有`combined_rules`和宿主`campaign_plan`。未启用的旧局不新增参与登记、不静默升级；历史日期不触发清场或满编恢复。此条件尚未迁移全部45场默认入口。

## 4. 故障与解释边界

长距离返场首次AFSIM进程在约0.16秒内退出1，stdout／stderr为空，故障任务`65abc844a8a647f7a72868a76fffd57f`。原世界停在第3轮，已确认返场命令未被消费。仅在确认该进程终止后，从原检查点经正常API再次执行，完成三段返场；没有自动重试、重建初态或修改前态。**原生进程早退的根因仍待查，无中断稳定性未因此通过。**

本轮DSH八轮的参与状态、兵力和粮弹叙述与已采样状态基本相符；仍观察到把未交火说成“未接敌”、把弹药指数65称“缺弹”的泛化。按X20保留正文和结算证据，机械通过不作为全文准确证明，不以新增正则宣称通用语义已解决。
