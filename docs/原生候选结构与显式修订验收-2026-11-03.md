日期：2026-11-03。状态：本分项完成实现和验证，整体工程继续改进；完整门禁及修复复测分开记载。原配置、历史资料、原对局及安装版不变，未上传。

## 问题与实现

前次正常前端 T4 在 24 次效果预览全拒收后失败。其中后 15 次为结构错误：`unit_name/name` 代替 `unit`、更新行附带只读 `team`、错误命令容器等。每次完整重发候选，累计参数 479619 字符；不是连接故障或单次输出预算耗尽。

新增共享 `effect-schema.json`，同时供 Cordis 原生工具参数及 Python 入口使用。预检逐项返回 JSON Pointer 路径、缺字段／未知字段／类型、允许字段。它只检查结构；数量、版本、火力、疲劳、补给、时钟、目标及来源继续由原领域校验负责，不是另一套通用 JSON Schema 引擎。

新增原生 `amend_turn_effects`：模型给出当前 `base_ref` 和显式 `add/replace/remove` 操作，插件从 DSH `snapshotEvents()` 选取相关公开工具调用／结果链，宿主逐条重建候选并完整重验。引用绑定当前操作、轮初世界及完整参数，另校验候选指纹。不保存第二份候选，不代填数值，不猜字段别名，不修改世界或命令队列。最终原子提交仍走原路径。

修订失败后，若候选已重建，会返回新引用供继续修订；缺证据、跨操作或路径非法不产生可用候选引用。报告和来源正文不能通过效果修订编辑。成功候选分页、战报提交及最终恢复都能核对完整链，继续兼容旧完整预览证据。工具只对主 Native 过程引擎开放，单位、问答和 AFSIM 规划角色不能使用。

## 离线门禁与最终复测

完整门禁执行了 **159 组、1847 项 unittest、0 跳过**，含依赖、上下文退化和干跑探针：**原始结果 158 组通过、1 组失败**，分组耗时合计 1131.14 秒。`verify_turn_settlement` 的 2 项失败均为跨操作／世界被正确拒收，但新通用错误缺少旧“指纹”分类；不是放过错误状态。

最终源码只补齐这句诊断，随后重跑结构、修订、结算、分页、战报及最终恢复 6 组共 **90 项**，全部通过，86.674 秒，包含原失败组全部 28 项。先前 19 项相关检查为 14.010 秒，重测不重复计入 1847 项。**没有把原始门禁文件改成全绿，也不声称完成过一次最终源码下全绿的全仓运行。** 复核汇总指向原门禁和最终复测两份证据，改动仅为诊断文案。

最终 `source-freeze-v4.json` 固定 48 份源码／测试文件，3 份 QA 辅助文件及 73 份受保护文件核对未变。原前端失败、两份浮点复制 QA 失败和前期未跑完的门禁都保留。最终源码精确恢复 7 份完整记录，重放真实 T4 的公开工具链及轮末指纹；UI 1440／900、22 标记、人员保有率和 0 写请求／页面错误核对。冷恢复后没有多推进物理回合。
