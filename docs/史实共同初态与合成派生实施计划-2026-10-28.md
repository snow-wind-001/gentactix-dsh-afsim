# 史实共同初态与合成派生实施计划

目标：合成演习从历史配置已验证的同一份具名初态派生，不再悄悄以CA代表编组替代。默认人数、装备、库存、位置、时钟和局部规则相同；用户随后可修改人数、装备、部署或增减编组。历史事实与到场快照只读，演习改动有独立身份与来源标记。

实现沿用当前Vue、ScenarioComposer、历史单位配置器、DSH原生skill/工具/取消与AFSIM编译执行。仅新增冻结输入派生合同，不新建执行器、工具循环或模型传输。旧CA存档保持原合同恢复；缺具名初态的战役明确显示缺口，不以教学模板冒充共同历史初态。

实施顺序：

1. TDD验证冻结基线、默认数值一致、双方1—12编组、同阵营来源绑定、独立派生身份、不可篡改事实、历史与演习隔离、恢复和旧存档兼容。
2. 抽取现有编组配置校验供冻结定义复用。派生保存完整历史计算绑定、改动配置和摘要；人员装备与过程运算仍交现有AFSIM。
3. 现有构建器增加从已验证历史草稿派生的入口；原生工具按当前操作固定来源，模型只编辑可修改参数。复用旧合成编辑器，支持直接保留基线与按需DSH调整。
4. 启动页合成模式先创建历史基础，随后编辑派生配置；地图点选与状态失效仍由现有组件管理。回溯分析仍只读来源事件，不因派生而改写历史。
5. 实际DSH生成历史基础、默认派生与修改编组，经真实AFSIM连续运行、控制命令、观察分析、独立恢复验证；宽窄界面与原数据保留检查。

验收不以此替代45场完整历史初态与全过程标定；时间窗、海空、地形及其他未建模能力仍按实际边界显示。
