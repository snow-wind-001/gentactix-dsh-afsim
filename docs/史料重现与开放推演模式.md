# 史料重现与开放推演

严格史料重现使用 `simulation_mode=replay`、`execution_backend=afsim`；其余想定使用开放推演。两者不能在同一战局中悄然切换。

## 严格史料重现

45个目录条目提供带来源的事件帧。长征15项、抗日战争20项复用已有结构化审订档案；抗美援朝9项、长平1项从现有史料卡摘编到 `data/history_replay/curated_events.json`。这些资料不是本轮新完成的原始档案核验，公开叙述中的争议、并列记载和未载信息继续保留。

`gentactix/history_replay.py`生成不可由模型改写的来源帧，摘要绑定完整资料版本。`backend/afsim_history.py`通过已有DSH原生MCP插件调用AFSIM：载入地名参考平台、执行事件帧、核对结束状态和帧摘要回执，成功后才原子提交检查点与轨迹。AFSIM不可用、取消、缺少回执或来源版本不符时，原帧保留；禁止回退到模型叙事或教学战损规则。

当前实现是**事件级重现**。它不是完整逐单位历史运动复原：多数资料缺少可核定的逐时坐标、到达表和人员装备账。地图点表示有来源的现代地名参考，不表示本帧军队部署；未载单位位置、逐帧伤亡均保持未知。战役总兵力、总损失及不同口径只展示为统计资料，不分摊到每帧。对于并列冲突记载，展示来源版本，不将其误当成两次独立战果。

历史时间按原资料的日期、时段、小时或相对顺序显示，不补写钟点。后台1秒为帧执行调度时间，与历史流逝时间无关。重复点击须匹配当前帧序号；到最后一帧后停止。回放不接受作战命令，不执行反事实，不将缺少部署的事件帧直接复制成开放战局。DSH问答、复盘只解释已提交资料和证据，不能写入战局。

## 开放推演

人工命令和DSH决策驱动下一步，允许合理偏离历史。史料用于背景、初始条件及规则边界，不能因历史日期到达就强制伤亡、位移或结局。

AFSIM模式默认使用与战役关联的统一团级合成教学初态。人员装备、炮兵、防空、航空、工兵、后勤指挥由已登记的AFSIM教学模型计算，应用持久保存完整状态，DSH按需读取。模型系数、编制与局部设施未作史实标定。开放想定的程序目标和反事实只对其可计算模型有效，不证明历史本来会发生同样结果。

## 验证入口

- `python verify_history_replay.py`：来源覆盖、未知值、篡改拒收、API模式、指令禁写、帧版本、失败原子性；测试执行器明确标为夹具。
- `python tools/qa/history_replay_audit.py`：全部45条目真实AFSIM装载，以及湘江全事件流程；禁止调用模型生成或Python教学战斗结算。
- 开放推演另用 `verify_combined_arms.py` 与 `tools/qa/combined_arms_audit.py --catalog`；两种测试证据分别记录。
