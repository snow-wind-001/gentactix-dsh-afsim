# 地图工作台折叠布局

目标：地图占据工作台主体，上方工具、左侧想定和右侧分析只在需要时展开。沿用Vue、Leaflet、现有数据和控制组件，不改推演接口、模型配置或存档。

## 组件与状态

`MapWorkbench.vue`负责布局与展开状态：顶部“推演操作／目标与运行／地图图层”，左侧“想定与控制”，右侧各分析标签。首次进入全部收起。面板浮于地图上，不改变地图容器尺寸；使用`v-show`保留折叠前的输入、滚动和组件状态。`App.vue`继续负责会话、命令、分析标签和所有API调用。

地图图层工具通过Vue Teleport进入顶部图层页。Leaflet实例保持挂载，现有ResizeObserver处理窗口变化。单位指挥仍由CommandCenter负责；开始指挥或地图选点时收起遮挡面板，打开工作台面板时关闭浮动指挥框。

## 交互与显示

- 桌面可按需同时打开左右页；宽度不足1100px时面板互斥。手机使用受视口约束的覆盖面板，各面板独立滚动，不把页面拉长。
- 标签具备`aria-expanded`、`aria-controls`、可见键盘焦点；Escape收起当前面板并把焦点还给入口。右侧标签支持方向键、Home、End。
- 时间、当前模式、忙碌与错误保留紧凑常驻提示；取消始终可达。完整来源、教学参数、目标和执行证据位于原组件中。
- 不新增自动推演、自动提交命令或模型调用。严格史料重现的禁写约束保持。

## 验证

类型检查、生产构建和原有离线回归；Playwright核验默认地图面积、三边面板展开／收起、标签切换、Escape焦点、草稿保留、图层保留、单位选择与地图选点。覆盖1440×1000、820×900、390×844和矮屏；测试前后比对已保存战局，验证布局操作没有推进或改写战局。

## 等待反馈与页签优化

地图顶部使用3px彩线指示运行状态：青色为等待/DSH处理，琥珀色为AFSIM或恢复/取消等待，绿色为已完成，红色为失败；取消单独标记。模型处理时长不可预知，运行线为不定进度，不显示虚构百分比。标题栏显示阶段与已等待时长，计时在独立组件内更新，不触发地图渲染。取消请求收到确认前保持等待状态。

进度轮询串行执行、单次5秒超时，操作结束或切换会话时中止旧请求；连接失败明确显示仍在等待。推进按钮保持原位并禁用，取消按钮单独出现，避免双击推进误触取消。左右入口采用弧形、与面板相连的侧向页签，保留原标签键盘和折叠行为。

地图只监听世界与图层的提交引用；聊天和等待元数据不触发全图重建。选中单位只更新已有标记样式，实际世界更新合并到下一帧处理。验收检查等待期间的交互、取消/失败/重试、计时、轮询中断、不虚报完成比例，以及单位标记和Leaflet实例在无战场变更时的稳定性。
