## 执行路径

此前的转换只验证候选世界、命令和持续任务。本次增加隔离执行入口 `backend/formation_execution.py`，复用现有 AFSIM 编译、DSH Native MCP 调度、原生回执解析，以及 DSH 的 `preview_turn_effects`／`submit_turn_report`链路。入口只返回分离的结果帧，不接纳运行会话、不保存用户对局。

AFSIM 每回合生成独立作业，并不持有一个需要增删实体的常驻战场。后续身份切换应在宿主原子完成，下一回合从当前损耗后的人员、装备、库存、余量、冷却与时间生成平台，不能从冻结初态重新满编生成。本次以既有真实T1检查点的副本验证该路径，保留原有1339人减员及分类装备损伤。

宿主回调绑定原定义、注册根账和同一／下一完整回合，普通 `missions.validate` 仍拒绝未准入的运行中转换。回调是内部可调用对象，不是模型可以提交的 JSON 开关；读写命令检查的私有作用域在外部进程启动前结束。
