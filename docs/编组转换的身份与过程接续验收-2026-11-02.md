# 编组转换的身份与过程接续验收

本轮完成 K05 的**脱离运行会话的完整世界候选校验**：已登记的分合兵提案可以接续有效身份、参与状态、战役演员和目标观察。仍未把新实体写入运行会话、命令、持续任务或平台；不关闭 K05、Q06／Q15 或45场270个完整历史窗口。

## 实现与状态策略

`missions`、`historical_operations.validate_identity` 和 `formation_parts.validate` 共同使用经登记重验的有效身份参考。原 `mission.definition`、历史快照及初始分队表保持不变；当前分队成员另由登记推导，不能拿冻结模板覆盖当前伤损。

新增 `formation_continuity.prepare`，在一个脱离会话的候选上完成接续。回执放在原归属事件的 `process_handoff`，不另建第二份可修改战场。回执保留前态摘要、原名单顺序和参与／战役／目标记录；针对当前同一时点的末次转换，验证器逆向重建前态、独立重算接续结果。候选 JSON 冷读必须再次验证。后续物理回合仍需正常过程校验及尚未接通的执行事务，不能据该回执宣称完整运行轨迹均已验收。

| 状态 | 接续规则 |
|---|---|
| 人员、分类装备、库存及余量 | 使用已核对的当前账分配；伤亡不恢复，未选单位保留当前状态 |
| 参与过程 | 继承实际状态与起始时刻；新身份自身转换次数从零计，原物理转换记录留在回执，另有可追溯来源；不能把共享祖先次数相加 |
| 到场与工事 | 从冻结原根身份读取到场安排、基础防护与工事值，保留当前完整度；不能因新下级名称缺少配置而提前入场 |
| 当轮被俘 | 对转换后容量互斥分配一次，不把整笔记录复制给每个分队 |
| 目标 | 原选择器解析到互斥的当前下级；保留原投入分母、里程碑、累计保持时间和采样时钟，只在物理观察完全等价时重绑定输入摘要 |
| 初始已过河分队 | 再次拆分仍沿原根保留预置通路，不被识别为未渡河单位 |

目标节点的 `unit_count` 继续表示冻结选择器数量；候选观察另提供 `active_entity_count`，区分一个原编制与多个当前计算实体。补给就绪按原选择组计数，细分不能获得额外完成收益。

带待处理退出请求、尚未入场或处于撤出／返场途中时拒绝转换。合并若改变压制、区域控制等目标观察，也拒绝零时间重绑定；后续须定义有代价的重组与重新采样规则。没有为了通过测试放宽历史下级“直接隶属且本阶段已在场”的来源要求。

无目标图的旧目标仅在临时副本上试算比较，副本丢弃；权威候选不推进、不结算、不发奖励。`continuity.goals_evaluated=false` 指权威候选未重新计分，不表示未做目标一致性检查。

## DSH接入与执行边界

沿用现有 `preview_force_conversion` 原生插件工具和 HTTP `conversion-preview`，不新增应用层聊天编排或一份模型战场。两者返回有界 `ownership` 与 `continuity` 摘要，完整世界和接续回执留在宿主。每页重新校验，受世界、命令和组织修订约束。

`world_prepared=true` 只说明候选通过过程校验；`runtime_admitted=false`、`command_task_platform_admitted=false` 仍然成立。普通 `missions.validate(world)` 明确拒绝这种候选进入会话，内部 `allow_prepared=True` 不向前端或模型开放，也不能通过校验缓存绕过普通入口。
