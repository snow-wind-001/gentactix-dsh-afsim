## 2. 架构与必须保留的不变量

```text
Vue / Leaflet / Electron
  → FastAPI：操作、命令、想定、存档与分支
  → 历史身份/阶段 + 多层编制/任务 + DSH Native工具
  → AFSIM原生执行 或 DSH结构化效果估计
  → 宿主校验、原子提交、完整检查点
  → 地图、人员装备库存账、公开决策轨迹和复盘
```

- 宿主检查点是唯一权威战场状态。DSH上下文、会话压缩与分析文字不能替代实体账；不要另建第二套状态、执行器或调度器。
- DSH已经使用原生工具、持久单位会话、角色工具权限、公开事件和恢复，不能继续描述为“仅持久聊天传输”。尚不能据此声称全面采用superagent或所有DSH能力。
- 历史战役回溯分析约束来源节点；历史战局推演允许决策改变；合成演习从历史基础编辑。AFSIM开关是独立维度。45场×三用途×两执行方式的270格完整历史验收仍未通过。
- SDK错误、取消、预算耗尽及持久化失败不能提交物理世界。有效中间候选不代替最终正常完成。保留失败证据，不读写私有推理，不手动压缩或降低用户思考配置。
- 人员、装备、粮弹、时钟与任务必须连续；分合兵不能恢复满编、复制库存或将历史总部当作物理步兵。估计配置与历史事实必须分开。
