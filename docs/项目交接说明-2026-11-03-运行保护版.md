## 3. 实际架构与必须保持的边界

```text
Vue / Leaflet / Electron
  → FastAPI：操作生命周期、命令、想定、分支、存档
  → 历史身份与阶段、分层编制、持续任务、DSH Native工具
  → AFSIM原生执行 或 DSH结构化效果估计
  → 宿主严格校验、原子提交、完整检查点
  → 地图、人员装备库存账、公开决策轨迹与复盘
```

宿主检查点保存唯一权威世界。DSH使用持久单位会话、原生工具、角色权限、公开事件、恢复及原生压缩；已不只是聊天传输层，但尚不能声称全面采用superagent，相关评估见[SDK与Superagent报告](DSH-Superagent适配评估与SDK升级-2026-11-01.md)。不得另建影子世界或重复执行器。

三用途分别为历史战役回溯分析、历史战局推演、合成教学演习；AFSIM开关是独立维度。严格回溯约束有出处的历史节点，开放推演允许改决策，合成演习从历史基础修改。45场×三用途×两执行方式的270格完整历史验收均未关闭。

取消、SDK错误、空输出或预算耗尽不能提交物理世界；中间候选有效也不能替代正常完成。人员、装备、粮弹、时钟及任务必须连续，重组不能补满兵力或复制资源。未知史实保持未知，估计参数显式标注；不以既定历史伤亡配额强制制造结果。不读取私有推理、不手动压缩、不下调用户思考与预算设置。
