## 2. 当前架构与必须保留的边界

主应用为 **Vue 3／Leaflet + Electron + FastAPI + DSH Native + 可选AFSIM**。根Streamlit、Worker和容器入口仍保留，不能只按早期Streamlit说明理解当前桌面流程。

```text
有版本的史料／初态／阶段／计算窗口
  → DSH skill生成参数，宿主校验来源、范围与配置
  → 地图选点／自然语言下令，形成持续命令与多层任务
  → Native工具读取当前世界、提出单位决策
  → AFSIM执行，或由DSH生成过程估计
  → 宿主核对身份、时钟、人员装备、补给与目标
  → 原子提交检查点，前端展示态势、公开决策和复盘
```
