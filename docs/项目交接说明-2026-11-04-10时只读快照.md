## 2. 当前架构与不可破坏的约束

桌面主路径是 **Vue 3 / Leaflet + Electron + FastAPI + DSH Native + 可选 AFSIM**。早期 Streamlit 与 Worker 入口仍保留，但不能代表当前桌面全部功能。

```text
有版本的史料、编制、阶段与计算窗口
  → DSH skill 生成参数，宿主校验来源、范围和固定输入
  → 地图选点、自然语言、单位命令与多层任务
  → Native 工具读取世界，模型提出单位决策
  → AFSIM 执行，或 DSH 提出过程与效果估计
  → 宿主校验身份、时钟、人员装备、保障及目标
  → 持久化提交，前端展示态势、公开决策与分析
```

| 界面、地图与桌面壳 | `frontend/src/`、`frontend/electron/` |

| 史料、历史初态与计算范围 | `corpus/`、`data/historical_initial/`、`data/campaign_windows/` |
