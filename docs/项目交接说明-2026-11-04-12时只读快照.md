## 2. 当前架构及边界

当前桌面主路径为 **Vue 3 / Leaflet → Electron → FastAPI → DSH Native → 可选AFSIM**。早期Streamlit与Cloudflare入口仍保留，不能据旧入口描述判断桌面功能。

```text
版本化史料、时段编制、历史阶段与计算窗口
  → DSH skill提出配置，宿主核对来源、范围与固定输入
  → 地图选点、自然语言、单位命令与兵团任务
  → Native工具按需观察，启用的单位Agent提出决策
  → AFSIM执行，或DSH提交过程与效果估计
  → 宿主核对身份、时钟、人员装备、资源及目标
  → 检查点提交，前端显示态势、回执、公开决策及分析
```

| 责任 | 主要文件/目录 |
|---|---|
| 地图、控制面板、桌面壳 | `frontend/src/`、`frontend/electron/` |
| 初始化、会话、存档及恢复 | `backend/main.py`、`backend/session_store.py`、`backend/scenario_assembly.py` |
| 历史来源与计算范围 | `corpus/`、`data/historical_initial/`、`data/campaign_windows/` |
| 编制、分合兵、持续任务、阶段续接 | `gentactix/force_*.py`、`formation_*.py`、`phase_continuity.py`、`campaign_plan.py` |
| 火力、运动和保障 | `gentactix/combat_effects.py`、`movement_feedback.py`、`supply_schedule.py`、`backend/afsim_*.py` |
| DSH会话、观察及候选校验 | `backend/harness_engine.py`、`backend/turn_preview.py`、`backend/effect_constraints.py`、`plugins/dsh-gentactix/`、`plugins/dsh-afsim/` |

权威态势保存在宿主世界与检查点，模型上下文用于决策和按需观察。模型返回、工具成功、回合提交和战役目标完成是不同状态。当前主用Native工具模式，既有记录为`ptc=false`；Superagent完整编排尚未验收，不应仅凭SDK升级宣称已经接入。

三种用途保持区分：**历史战役回溯分析**按来源事件与顺序重现；**历史战局推演**和**合成教学演习**允许改变决策。三种用途均可选择开关AFSIM。来源帧回放和程序目标完成均不能单独证明完整物理历史过程已经复现。
