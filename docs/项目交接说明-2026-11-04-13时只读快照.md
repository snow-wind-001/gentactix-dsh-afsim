## 2. 当前架构与实际能力

桌面主路径为 **Vue 3／Leaflet → Electron → FastAPI → DSH Native → 可选AFSIM**。根目录`AGENTS.md`仍保留早期Streamlit／Cloudflare入口说明，不能仅据该说明判断当前桌面架构；本次遵守要求没有改写它。

```text
版本化史料、参战身份、历史阶段、计算窗口
  → DSH skill与既有Native配置工具生成候选
  → 宿主校验来源、范围、固定输入和模型合同
  → 地图选点／自然语言／单位及兵团任务
  → 按需观察、单位Agent或人工命令
  → AFSIM实际执行，或DSH提交过程与效果估计
  → 校验身份、时钟、人员装备、资源账和目标
  → 检查点提交，前端展示态势、回执和公开决策
```

权威态势保存在宿主世界和检查点，不依赖模型上下文保存全部战场。当前主路径是Native工具模式，既有记录为`ptc=false`；已有持久角色会话、分页观察、原生工具、取消和原生上下文压缩的实测。**Superagent完整编排尚未验收**，SDK版本更新不自动代表项目已使用该能力。
