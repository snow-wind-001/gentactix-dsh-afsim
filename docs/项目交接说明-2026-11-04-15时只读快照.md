## 2. 架构与已建立的能力

桌面主路径是 **Vue 3/Leaflet → Electron → FastAPI → DSH Native → 可选AFSIM**。根目录`AGENTS.md`仍描述早期Streamlit/Cloudflare入口；本次遵守既有要求，没有修改它。新接手者不能只据旧入口说明判断桌面产品架构。

```text
版本化史料、参考身份、阶段与计算窗口
  → DSH skill及现有Native分片配置工具
  → 来源/固定输入/范围/物理合同校验
  → 地图选点、单位命令、自然语言草稿与兵团任务
  → AFSIM实际执行，或DSH提交过程及效果估计
  → 身份、时钟、人员装备、资源和目标核对
  → 宿主检查点提交、界面显示、公开决策与复盘
```

权威态势保存在宿主世界与检查点，模型通过按需、分页工具观察，不靠上下文承载全部战场。既有实测主路径为Native工具模式、`ptc=false`；保留应用层兼容协议。已有持久角色、工具事件、取消、分页观察及DSH原生压缩的实测。公开决策和工具轨迹可展示，私有思考不属于产品决策说明。

三种用途为历史战役回溯分析、历史战局推演、合成教学演习，都可选开关AFSIM。回溯遵循来源关键节点和顺序；开放历史与合成允许改变过程和结果。**来源事件播放、真实战斗执行、程序目标完成和历史效能正确，是四种不同验收结论。** 回溯中用来源帧/参考地名展示未知部署，不等于已经生成可交战的完整部队初态。
