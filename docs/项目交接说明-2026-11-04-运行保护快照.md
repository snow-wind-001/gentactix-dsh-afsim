## 2. 当前架构与状态权威

```text
Vue 3 / Leaflet地图工作台，Electron桌面壳
  → FastAPI配置、操作生命周期、命令、存档
  → 固定版本史料、阶段、计算窗口、编制与实体
  → DSH Native skill / 领域工具生成配置和决策
  → AFSIM计算，或DSH提交独立过程估计
  → 宿主核验身份、时间、资源与目标，提交检查点
  → 前端态势、公开决策、账目与复盘
```

**权威战场状态在宿主检查点，不依赖模型上下文独自保存。** DSH上下文负责按需读取、规划和解释；模型提出的候选须通过校验才进入世界。失败候选不等于已执行动作。

|---|---|---|
| 前端与桌面 | `frontend/src/`、`frontend/electron/` | 标图图层与实际运动、火力和地形效果分开 |
| 操作、配置与持久化 | `backend/main.py`、`scenario_assembly.py`、`session_store.py` | 防重复提交；保持类型、身份、版本、轨迹及失败证据 |
