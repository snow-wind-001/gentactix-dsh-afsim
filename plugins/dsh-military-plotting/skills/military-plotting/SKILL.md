# 军事标图

先用`search_military_symbols`按用户要表达的对象检索应用符号及参考编号。目录中的`source_ids`可追溯本地军事标图样例；自动笔画分组、整页和未知图形不是可用的独立军标。应用图例不宣称符合某版现行标准，颜色只表示演习阵营，不推定国别或敌我；重绘符号不证明历史装备配属。

从用户地图选点、已知单位和保障节点位置构造草稿。不要编造经纬度；没有足够点位时说明需要在地图补点。路线用实际顶点表达，不把静态箭头示例当作历史行军轨迹。点符号的定位点由目录提供：指挥所用旗杆脚，其他以登记锚点落位；不要自行平移坐标补偿图形。

只返回`{"items":[...],"explanation":"简短说明"}`。每项包含`symbol_id`、`label`、`team`（red/blue/neutral）、`status`（planned/assumed/observed）、`points`（lat/lng对象数组）、`source`、`visible:true`。点1顶点、线2–32顶点、地域3–32顶点；最多12项。已知单位可用`unit_id`绑定点标注跟随位置。ID由宿主分配。observed须有来源；模型不能自行把计划或估计升级为已核实史实。

提交前调用`validate_military_plotting`，修正校验反馈再给最终结果。工具校验不保存标注；用户确认后才持久化。不要输出SVG、HTML、文件路径、作战命令、人员装备损耗或战局状态。标注仅为表达图层，不创建部队，不改变道路、桥梁、视线、战损、控制权或AFSIM规则。
